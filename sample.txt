Welcome to Prompter!

This is a sample text file to test the teleprompter application.

The Prompter application allows you to:

1. Load any text file
2. Automatically scroll the text at a configurable speed
3. Keep the window always on top of other applications

This makes it perfect for:
- Video presentations
- Live streaming
- Public speaking
- Recording tutorials

You can control the scrolling speed using the slider at the bottom of the window.

The Start/Stop button lets you pause and resume scrolling at any time.

Press Reset to go back to the beginning of the text.

Try adjusting the speed while the text is scrolling to find your perfect reading pace!
